This is the schema (meta-graph) of the BioBTree knowledge graph — the biolink entity categories and the typed relationships between them, drawn from 150+ integrated biological datasets. Each node is a category; click it to see the contributing datasets (separated into primary sources with their own records and cross-reference namespaces that only supply identifiers) and the relationships it participates in. This is the schema view; a separate importable subgraph (human + disease + molecule) is published alongside it.

👈 Click any node to reveal its connections — or hover to preview. Press / to search.
